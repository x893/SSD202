Install toolchain

Copy the gcc-arm-8.2-2018.08-x86_64-arm-linux-gnueabihf.tar.gz files to the virtual
machine /opt folder
Unzip the compressed package
	tar -zxvf gcc-arm-8.2-2018.08-x86_64-arm-linux-gnueabihf.tar.gz

Unzip multiple files with the same suffix command

	for tar in *.tar.gz; do tar xvf $tar; done

Unzip multiple files with the same suffix to the specified folder command

	for tar in *.tar.gz; do tar xvf $tar -C /home/; done

Set the toolchain to the environment variable.
Download the cross-compiler (https://cowtransfer.com/s/e7b3ca8c73c34d) tool and use the transmission password: je6lak extraction
Add in /etc/profile:export PATH=/opt/gcc-arm-8.2-2018.08-x86_64-arm-linux-gnueabihf/bin:$PATH

It will take effect when you reopen a terminal after completion

4. The compilation process

Put the package in the ubuntu system.
After decompressing the boot, kernel, project, and sdk compressed packages
in the SDK package of TAKOYAKI_DLC00V030 version,
the corresponding package files are obtained respectively.

1. Compile the boot process

Enter the terminal into the boot folder directory and execute the following command

Set environment variables
	declare -x ARCH="arm"
Set build environment variables
	declare -x CROSS_COMPILE="arm-linux-gnueabihf-"

Select the corresponding onboard flash type to execute the configuration command
SPInor Flash type
	make infinity2m_defconfig //spinor, execute the corresponding command according to the onboard flash type
SPInand Flash type
	make infinity2m_spinand_defconfig//Spinand, execute the corresponding command according to the onboard flash type

Open menuconfig to visualize the configuration, if no configuration is required.
Skip this command to
	make menuconfig//modify && save

Clear build content
	make clean
Start compiling
	make

2. Compile the kernel process

Enter the terminal into the kernel folder directory and execute the following command

Set environment variables (no need to execute if executed in the same terminal as boot)
	declare -x ARCH="arm"
Set the compilation environment variables (if it is executed in the same terminal as boot, it does not need to be executed again)
	declare -x CROSS_COMPILE="arm-linux-gnueabihf-"

Select the corresponding onboard flash type to execute the configuration command
SPInor Flash Type
	make infinity2m_ssc011a_s01a_minigui_defconfig//SSD20x spinor
SPInand Flash Type
	make infinity2m_spinand_ssc011a_s01a_minigui_defconfig//SSD20x Spinand

Open menuconfig to visualize the configuration, if no configuration is required. Skip this command to
	make menuconfig//modify && save
Clear build content
	make clean
Start compiling
	make

3. Compile SDK process

Enter the terminal into the project folder directory and execute the following command

Select the corresponding onboard flash type to execute the configuration command
SPInor Flash Type
	./setup_config.sh ./configs/nvr/i2m/8.2.1/nor.glibc-squashfs.011a.64/SSD20x Spinor
SPInand Flash Type
	./setup_config.sh ./configs/nvr/i2m/8.2.1/spinand.glibc.011a.64/SSD20x Spinand
Clear build content
	make clean
Start compiling
	make image

4. Get the compiled images update package

After compiling the above files, under the project/image/output/images folder are the files we need to update to the development board. Update the contents of the entire images folder to the SSD202 development board through the tftpd tool.

Note: If you want to update uboot and kernel, you need to compile the project first,
then copy the bins of uboot and kernel to
/yourpath/xxx/image/output/image, the kernel is uImage.xz -> kernel.

Or execute the make image script when compiling the SDK.
After compiling, the firmware compiled by the boot and kernel will be automatically
copied to the corresponding location.
