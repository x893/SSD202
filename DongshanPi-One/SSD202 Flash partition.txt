1 Partition Description
The examples in this article use SPI NAND flash devices

CIS:
The unique partition of SPI-NAND, which is stored in the 0 address of the flash. It contains two parts:
one part is spinand info, which saves some basic information of spinand devices; the other
part is partinifo, which saves partition information

IPL:
The CPU starts and loads the startup code in the ROM, loads the 0 address code of the FLASH, obtains the code of this partition and runs it.
This partition code initializes some basic hardware, such as setting the current DDR parameters, and GPIO /IIC related.

IPL_CUS:
Initialize customized board hardware, such as GPIO, IIC, etc., according to the actual situation of the current board.

UBOOT:
As the title says.

ENV:
UBOOT's environment variable storage partition.

LOGO:
The configuration and data related to the boot logo.

KERNEL:
As the title says.

ROOTFS:
As shown in the title.

miservice:
a library for storing mi; some configurations such as memory and screen.
For details, please refer to the miservice partition establishment process of https://blog.csdn.net/winner0911/article/details/124174631

appconfigs
The client's own custom application configuration.

customer:
The application customized by the customer.

2 Partition change production steps
According to project definition spinand.glibc.011a.128 file:
IMAGE_CONFIG = spinand.ubifs.p2.partition.config
According to spinand.ubifs.p2.partition.config file
IMAGE_LIST = cis ipl ipl_cust uboot logo kernel rootfs miservice customer appconfigs

4 Add a new partition
Add the name of the partition to the IMAGE_LIST in the IMAGE_CONFIG = spinand.ramfs-squashfs.p2.partition.config
file and
add the configuration parameters corresponding to the partition, such as type, size, etc.
The system will automatically generate it during the compilation process.

5 script_nand.mk generates uboot script
image/configs/i2m/script_nand.mk
Remember to check whether the content of the script file is the same as required.
It affects programming and system mounts.
